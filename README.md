## المحتويات
- `index.html` — ملف الموقع الرئيسي. الأسعار والحجز وحساب الإجمالي تعمل داخله.
- لا توجد ملفات صور منفصلة؛ صور الرحلات مرتبطة بمصادر خارجية وتحتاج اتصالًا بالإنترنت.

## الرفع
ارفع محتويات هذا المجلد إلى جذر المستودع على GitHub، ثم فعّل GitHub Pages من الفرع والمجلد الذي ترفع إليه الملفات.
